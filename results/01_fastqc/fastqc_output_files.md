# FastQC Output Files

The FastQC step generates two output files for each sequencing sample.

| File | Description |
|------|-------------|
| *.html | Interactive quality assessment report |
| *.zip | Compressed archive containing FastQC metrics |

Example:

- SRR11603071_fastqc.html
- SRR11603071_fastqc.zip
- SRR11603072_fastqc.html
- SRR11603072_fastqc.zip
- SRR11603073_fastqc.html
- SRR11603073_fastqc.zip
- SRR11603080_fastqc.html
- SRR11603080_fastqc.zip
