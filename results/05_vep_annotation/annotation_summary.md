# Functional Annotation Summary

## Overview

Functional annotation was performed using the **Ensembl Variant Effect Predictor (VEP)** to determine the potential biological impact of the variants identified by GATK HaplotypeCaller.

The analysis assigned genomic variants to genes, transcripts, and predicted functional consequences.
