## Information Provided

Each annotation report includes:

- Variant location
- Gene name
- Transcript ID
- Consequence type
- Variant impact
- Existing variant identifiers
- Functional annotations

---

## Purpose

The annotation reports provide biological context for each identified genomic variant, enabling downstream interpretation and prioritization.
