# Pipeline Output Summary

The DNA-Seq Variant Calling and Functional Annotation Pipeline generated the following outputs:

| Stage | Primary Output |
|------|----------------|
| FastQC | HTML Quality Reports |
| fastp | Trimmed FASTQ Files |
| BWA-MEM | SAM Alignment Files |
| SAMtools | BAM Files |
| Picard | Processed BAM Files |
| GATK HaplotypeCaller | VCF Files |
| Ensembl VEP | Functional Annotation Reports |

---

## Final Deliverables

- High-quality processed sequencing reads
- Reference-aligned BAM files
- Variant Call Format (VCF) files
- Functional annotation reports
- Gene and transcript annotations
