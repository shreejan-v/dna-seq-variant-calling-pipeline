# Example Outputs

## Overview

This directory contains representative outputs generated during the DNA-Seq Variant Calling and Functional Annotation Pipeline.

The files are intended for demonstration purposes only and provide examples of the formats produced at different stages of the workflow.

---

## Contents

| File | Description |
|------|-------------|
| example_variants.vcf | Example variant records generated by GATK HaplotypeCaller |
| example_vep_annotation.txt | Example functional annotation produced by Ensembl VEP |
| pipeline_output_summary.md | Summary of the pipeline outputs |

---

## Purpose

These example files allow users to understand the structure and interpretation of pipeline outputs without requiring access to the complete sequencing dataset.
